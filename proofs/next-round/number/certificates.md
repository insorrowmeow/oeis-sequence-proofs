Поэтому последовательность первых разностей с индекса 1 удовлетворяет правилу Падована $d_n=d_{n-2}+d_{n-3}$ при $n\ge4$. Её три начальных члена $2,3,4$ равны $P_9,P_{10},P_{11}$. ### Почему конечный сертификат доказывает результат для всех индексов

1. Строим последовательность $b_n$ по предлагаемой линейной рекурсии. Первые $d$ значений вычисляем от исходной пары по точному правилу округления. Обозначим $D_n=b_n b_{n+2}-b_{n+1}^2$. При строгом округлении вниз проверяем две последовательности $U_n=-D_n$ и $V_n=b_n+D_n$. Условия $U_n>0,V_n\ge0$ эквивалентны правильному округлению и влекут $b_n>0$. При чередовании проверяем $U_n=(-1)^nD_n$, $V_n=b_n-U_n$. Для двух дополнительных примеров округления к ближайшему целому с выбором нижнего при равенстве проверяем $U_n=b_n-2D_n$, $V_n=b_n+2D_n$. Во всех случаях достаточно доказать строгую положительность обоих выражений для $n\ge80$ и проверить разрешённые границы до 80.

2. Пусть $B$ — матрица сдвига окна $v_n=(b_n,\ldots,b_{n+d-1})$. Она постоянна. Величина $D_n$ является координатой внешнего произведения $v_n\wedge v_{n+1}$, а именно минором первых двух координат. Эти миноры эволюционируют под действием постоянной матрицы $\wedge^2 B$. Для $(-1)^nD_n$ берём $-\wedge^2 B$. Следовательно, обе проверяемые последовательности являются линейными функционалами состояния размерности $M=d+\binom d2$ с постоянной матрицей перехода.

3. Процедура `shortest_rule` подбирает целочисленную рекурсию для каждого функционала. Для доказательства этой рекурсии достаточно $M$ последовательных нулевых невязок, начиная с первой. Действительно, невязка также линейна по состоянию и поэтому удовлетворяет характеристической рекурсии размерности $M$ по теореме Кэли–Гамильтона. Проверка этих $M$ равенств вынесена из процедуры подбора в отдельное утверждение программы.

4. Имея доказанную рекурсию, рассматриваем подпоследовательности с одинаковым остатком индекса по модулю $s$. Их характеристическая рекурсия получается возведением характеристических корней в степень $s$ с сохранением кратностей. Это справедливо для характеристического многочлена степени матрицы сдвига даже при жордановых клетках. В коде `stride_rule` коэффициенты вычисляются тождествами Ньютона в целых числах.

5. Пусть $w_j=c_1w_{j-1}+\cdots+c_kw_{j-k}$ — рекурсия для одного класса остатков. Программа находит числа $0<L\le H$, для которых условие $L\le w_i/w_{i-1}\le H$ для предыдущих отношений воспроизводит само себя. После деления рекурсии на $w_{j-1}$ слагаемое с $c_{i+1}$ лежит между $c_{i+1}/L^i$ и $c_{i+1}/H^i$ в том или другом порядке. Рациональные границы для суммы входят в $[L,H]$. Код проверяет все исходные отношения и положительное первое значение для каждого из $s$ классов. Индукция даёт $w_j>0$ для всего хвоста. Отсюда $b$ удовлетворяет исходному нелинейному правилу на каждом шаге и совпадает с его единственным решением.
