# A carry-free factorization from the last update

The conjecture asks whether every odd output k = 2n+1 of the following loop is an odd composite admitting binary multiplication without carries. Start at A=n and, while A<2n, write A=2ᵗm with m odd, then add the smaller of 2ᵗ and m. [Original question and program](https://mathoverflow.net/questions/464360/possible-subsequence-of-the-a110978)

For n=0 the condition on the output fails. For n>0 the positive increment ensures termination. If the output is 2n+1, there must be a last update from some A<2n. Its exponent t cannot be zero, since an odd A gets incremented by one and becomes even. Thus A is even. Adding 2ᵗ would again give an even number, so the increment must be m<2ᵗ. It cannot be one, since then A would equal 2n, contrary to the loop guard. Consequently

    k = (2ᵗ+1)m,     1 < m < 2ᵗ,     t ≥ 1.

Both factors exceed one. The only nonzero rows of this binary multiplication are m and its shift by t bits. The first row ends below bit t and the second starts at bit t, so no column has two ones. This proves the stated inclusion for every input.

The Lean 4.19.0 file [CarryFree.lean](CarryFree.lean) checks the factorization, the nontriviality bounds and disjointness at every bit position for any reachable output satisfying k=2n+1. Reach encodes each guarded update by its power-of-two/odd decomposition. Termination is the elementary argument above.
