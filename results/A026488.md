# Все члены последовательности Кимберлинга A026488

Первый член равен 1. Каждый следующий — наименьшее целое число $m$, большее предыдущего члена, которое нельзя записать как $xy-z$. Здесь $x\le y\le z$ выбираются из уже принятых членов и самого проверяемого $m$. Значения могут повторяться. Такой выбор точно соответствует условию $i\le j\le k\le n$ для индексов строго возрастающей последовательности. [Исходная запись OEIS A026488](https://oeis.org/A026488)

Докажем, что последовательность состоит из числа 3 и всех положительных чисел, дающих остаток 1 при делении на 3. Обозначим это множество через $S$.

**Почему алгоритм принимает каждое число из $S$.** Если $m\in S$, то при проверке предполагаемого равенства $xy=m+z$ все четыре числа лежат в $S$. Пусть $m\equiv1\pmod3$. При $z\equiv1\pmod3$ правая часть даёт остаток 2, тогда как произведение слева может дать только 0 или 1. Остаётся $z=3$. Тогда $x,y\in\{1,3\}$, а сравнение по модулю 3 требует $x=y=1$. Но $1<m+3$. Для $m=3$ кандидаты — 1 и 3. При $z=1$ произведение равно 1, а при $z=3$ возможны произведения 1, 3 и 9. Они не равны соответственно 4 и 6.

**Почему алгоритм пропускает каждое положительное число вне $S$.** В таблице $t$ — любое целое число от нуля и выше. Каждая строка задаёт тройку в требуемом порядке, для которой $xy-z=m$.

| Проверяемое $m$ | $x$ | $y$ | $z$ |
|---|---:|---:|---:|
| $2$ | 2 | 2 | 2 |
| $5$ | 3 | 3 | 4 |
| $6$ | 3 | 3 | 3 |
| $8+6t$ | 3 | $4+3t$ | $4+3t$ |
| $11+6t$ | 3 | $7+3t$ | $10+3t$ |
| $9+9t$ | 4 | $4+3t$ | $7+3t$ |
| $12+9t$ | 4 | $4+3t$ | $4+3t$ |
| $15+9t$ | 4 | $7+3t$ | $13+3t$ |

В первой строке используется сам кандидат 2. Во всех следующих строках три числа лежат в $S$ и меньше $m$. Первые две прогрессии охватывают все $m\ge8$, сравнимые с 2 по модулю 3. Последние три охватывают все кратные трём начиная с 9.

Теперь проверяем положительные числа в порядке возрастания. Если все меньшие числа классифицированы верно, две части доказательства дают правильный ответ для текущего кандидата. По индукции алгоритм принимает ровно $S$. В частности, его первые члены равны $1,3,4,7,10,13,16$.

Lean 4.19.0 проверяет оба шага в файле `Kimberling.lean`. Теорема `expected_obeys_rule` доказывает, что $S$ удовлетворяет правилу отбора, а `a026488` устанавливает по сильной индукции, что всякий результат этого отбора совпадает с $S$. Для проверки достаточно стандартной библиотеки Lean.
