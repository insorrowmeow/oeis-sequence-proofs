## Сборка и проверки

Из корня проекта, в окружении с elan, выполните команды ниже. Версия Lean 4.19.0 и ревизия Mathlib зафиксированы. Все девять модулей входили в одну проверенную сборку.

```sh
lake exe cache get
lake build
python binary/check.py
python check_hankel_ca.py
python words/check_rook.py
python counts/verify.py
python combin/check.py
```

Для сверки с опубликованной таблицей A275667 можно передать её локальный файл программе `check_hankel_ca.py` через `--a275667`. Запускайте Python с включёнными проверками `assert`.

Для каждой записи указаны формулы, условия и охват проверки. Родственные формулы и частные случаи приведены вместе. Поиск по первоисточникам не устанавливает исторический приоритет. Работа выполнена с помощью ИИ.
