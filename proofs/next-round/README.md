В заметке о спирали разобрана также [A303605](https://oeis.org/A303605). Два прочтения правила дают разные числа на пятом шаге. Вариант с двумя различными позициями цифр воспроизводит 60 опубликованных значений. Это наблюдение приведено отдельно от гипотезы о спирали. В заметке о рекурсиях отдельно указаны два ранее известных контрольных случая, A021004 и A021008.

## Как воспроизвести

В корне распакованного проекта с установленным elan выполните следующие команды. Версии Lean и зависимостей зафиксированы в проекте.

```sh
lake exe cache get Mathlib.Data.Nat.Basic Mathlib.Tactic.NormNum Mathlib.Tactic.Ring Mathlib.Tactic.Linarith
lake build
```

Проверки на Python 3 используют стандартную библиотеку. Запускайте их в обычном режиме, с включёнными утверждениями `assert`.

```sh
python check_navarrete_mathar.py
python seq/check_digit_spiral.py
python seq/check_dyadic.py
python comb/verify.py
python number/verify.py
```

Первый скрипт также принимает пути к таблицам OEIS через `--a318698` и `--a318699`. При проверке совпали все 10 001 и 100 опубликованных значений соответственно. В скрипте для рекурсий положительность на бесконечном хвосте устанавливает индукция с точными рациональными границами. В остальных скриптах проверяются конечные примеры, а доказательства общих утверждений приведены в заметках.

Материалы подготовлены с помощью ИИ. Ссылки указывают на формулировки и найденные предшествующие работы. Исторический приоритет не установлен.
