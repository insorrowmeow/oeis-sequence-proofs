A340138. Перестановка, скорость роста и распределение остатков

Постановка

Пусть a(1) = 0. После a(n) выбираем наименьшее ещё не
использованное неотрицательное целое, десятичная запись которого
содержит цифру d(a(n)). Здесь d(0) = 0, а d(x) = 1 + ((x−1) mod 9)
при x > 0. Это цифровой корень. Первые члены: 0, 10, 1, 11, 2, 12.
В заголовке OEIS перед a(n+1) стоит ссылка на a(n−1). В определении
автора, в его программе и в таблице используется непосредственно
предыдущий член. Именно это правило здесь исследуется.

Дэвид Сайкамор предложил последовательность, а Майкл Де Влигер
сформулировал вопрос о перестановке и исследовал график и остатки.
https://oeis.org/A340138
https://w.vincico.com/seq/a340138.html

Теорема 1. Каждое неотрицательное целое встречается ровно один раз.

На каждом шаге имеется бесконечно много целых, содержащих запрошенную
цифру. Из них исключены только уже выбранные. Следовательно, выбор
существует и повторений нет.

Возьмём любое число M, содержащее все десять цифр. Пока M не выбрано,
оно подходит на каждом шаге. Жадное правило может откладывать его,
только выбирая различные числа меньше M. Их конечное число, значит,
M обязательно появится.

Зафиксируем d от 1 до 9. Для каждого k ≥ 0 возьмём число

    M(d,k) = 10¹⁰(d+9k) + 1234567890.

Оно заканчивается всеми десятью цифрами и имеет цифровой корень d:
10¹⁰ ≡ 1 (mod 9), а сумма цифр суффикса равна 45. При различных k
эти числа различны. По доказанному каждый из них появляется, так что
цифра d запрашивается бесконечно много раз.

У каждого положительного x есть ненулевая цифра d, например первая.
Пока x остаётся пропущенным, при каждом запросе d выбирается либо x,
либо меньшее число. Бесконечно много раз выбрать различные числа
меньше x невозможно. Значит, x появится. Ноль появляется в начале.

Тот же довод устанавливает свойство перестановки и для буквального
варианта с запаздыванием на один дополнительный шаг, если задать
два различных начальных члена 0 и 10 и применять правило с третьего.
Числа M(d,k) по-прежнему подходят при любом запросе; каждое из них
вызывает запрос d на один шаг позже. Уже третий член у этого варианта
отличается от таблицы OEIS (20 вместо 1). В Lean проверена именно
последовательность из таблицы.

Файл FrayedRope.lean строит последовательность с помощью точного
минимума, доказывает существование каждого следующего члена и
проверяет теорему 1 (A340138_permutation). Использован Lean 4.19.0
с mathlib. В проекте mathlib v4.19.0 команда проверки:

    lake env lean FrayedRope.lean

Теорема 2. Положим α = log₁₀9, так что 0 < α < 1. Тогда

    a(n) = n + O(n^α).

Для каждого фиксированного q ≥ 1 и каждого класса r по модулю q
среди первых n членов число представителей класса равно

    n/q + O(n^α).

В частности, a(n)/n → 1, а каждая из девяти положительных цифр
запрашивается с предельной частотой 1/9. Далее дано отдельное
письменное доказательство теоремы 2.

1. Числа, в которых нет заданной цифры. Среди положительных чисел
длины j таких чисел не более 9^j: для каждой из j позиций остаётся
не более девяти вариантов. Суммируя до L = ⌊log₁₀ X⌋+1, получаем
не более C X^α таких чисел в [1,X] с абсолютной константой C,
единой для всех десяти цифр. Учёт нуля меняет оценку не более чем на 1.

2. Верхняя оценка. После n шагов в множестве S_n первых n значений
ровно n элементов. Если в [0,X] больше n чисел с требуемой цифрой,
хотя бы одно ещё свободно и a(n+1) ≤ X. Возьмём
X = ⌈n + B n^α⌉. Для достаточно больших n имеем X ≤ 2n. Выбирая
B > C·2^α+2, получаем X+1−C X^α−1 > n. Поэтому все элементы S_n
не превосходят n + O(n^α), с единой константой; конечное число
малых n поглощается увеличением константы.

3. Остатки. Пусть I_n = {0,…,n−1}. Множества S_n и I_n имеют
одинаковую мощность. Числа S_n вне I_n лежат в полосе ширины O(n^α)
сразу над I_n. Следовательно, как |S_n ∖ I_n|, так и |I_n ∖ S_n|
равны O(n^α). В I_n число представителей каждого класса по модулю q
отличается от n/q не более чем на единицу. Замена I_n на S_n
изменяет это число на O(n^α). Для цифровых корней используем q = 9
и отдельно учитываем начальный ноль.

4. Нижняя оценка. Пусть x = a(n), 1 ≤ x < n. После первых x членов
число x ещё свободно. В [0,x] к тому моменту свободны O(x^α)+1
чисел по пункту 3 (сравнение S_x и I_x). Выберем ненулевую цифру d
числа x. При любом запросе d с момента x до момента n−1
включительно следующий член не превосходит x. Значит, суммарно таких
запросов не больше O(x^α)+1, так как использованные числа различны.
С другой стороны, по пункту 3 среди a(x),…,a(n−1) имеется
(n−x)/9 + O(n^α) членов с цифровым корнем d (вычитаем два префикса).
Отсюда n−x = O(n^α). Вместе с пунктом 2 это доказывает оценку.

Теорема 3. Пусть i(x) — индекс числа x в последовательности.
Существует целое c, для которого i(10^k) = 10^k + c при всех
достаточно больших k.

Для доказательства нужна точка, где жадный процесс точно возвращается
к обычному порядку чисел. По теоремам 1 и 2 имеем a(n)/n → 1 и
i(x)/x → 1: при x → ∞ положим n=i(x), тогда n → ∞ и x=a(n).

Обозначим N = 10^k, B = 0.9123456780 N, C = 0.9123456781 N.
При k ≥ 10 это целые числа. Все целые из [B,C) начинаются с
десятичных цифр 9123456780, а потому подходят при любом запросе.
Положим t = ⌊(B+C)/2⌋. Утверждаем, что для всех достаточно больших k
первые t значений составляют ровно {0,…,t−1}, а a(t)=t−1.

Действительно, каждое y<B к моменту t−1 уже появилось, поскольку
max_{y<B} i(y) ≤ B+o(N). Эта равномерная оценка следует из i(y)/y → 1,
отделяя конечный начальный отрезок. Аналогично max_{j≤t} a(j) ≤ t+o(N),
поэтому ни одно y≥C к моменту t ещё не выбрано. Здесь важна ширина
блока: разности t−B и C−t обе составляют фиксированную положительную
долю N. В самом блоке числа могут впервые выбираться только в порядке
возрастания, так как все они подходят на каждом шаге. Таким образом,
как после t−1, так и после t членов множество посещённых чисел есть
начальный отрезок. Его длина однозначно определяет последний шаг.

Положим H=9N. Те же рассуждения верны для блока [B+H,C+H) и времени
t+H: у чисел блока в начале дописана ещё одна девятка, а ширина
по-прежнему составляет фиксированную долю масштаба. Значит, в два
рассматриваемых момента значения равны t−1 и t+H−1 и все меньшие
числа уже использованы.

Теперь сравним шаги после этих двух моментов. При t ≤ y < N число
y начинается с 9, а прибавление H приписывает слева ещё одну 9.
При N ≤ y < 1.1N начальные цифры y равны 10; прибавление H вставляет
после единицы ещё один ноль. В обоих случаях множество цифр y+H
точно такое же, как у y, и цифровые корни одинаковы, так как 9|H.
У самих t−1 и t+H−1 цифровые корни также одинаковы.

Имеем i(N)=N+o(N)>t и max_{j≤i(N)} a(j) ≤ N+o(N) < 1.1N при больших k.
До выбора N меньший из двух процессов поэтому каждый раз выбирает y
из диапазона [t,1.1N). По индукции больший выбирает y+H: числа меньше
t+H там уже использованы, а все кандидаты между t+H и y+H в точности
соответствуют кандидатам от t до y, с теми же цифрами и статусом
использования. Нужная цифра та же по равенству цифровых корней
предыдущих членов. На шаге выбора N получаем i(10N)=i(N)+9N.
Отсюда i(10N)−10N = i(N)−N для всех достаточно больших k, что и
доказывает стабилизацию. Доказательство не определяет значение c.

Дополнительная вычислительная проверка

У автора приведены точные позиции 10^k для k = 1,…,5 и задан вопрос,
всегда ли 10^k появляется до позиции 10^k. Программа measure.ps1
считает последовательность по определению. Для k = 6, 7, 8, 9 она даёт
позиции 999958, 9999958, 99999958 и 999999958 (нумерация с 1).
Диапазон k = 4,…,9 согласуется с c = −42. Равенство c = −42 и
вопрос о знаке для всех k остаются открытыми. Для воспроизведения
в PowerShell:

    ./measure.ps1 -Count 1000000100

Независимая программа check_oeis.py перебрала допустимые значения
с единицы на каждом шаге и сверила все 10 000 официальных членов.
Таблица для воспроизведения: https://oeis.org/A340138/b340138.txt

Численное наблюдение о степенях десяти не используется в доказательствах.
Поиск по идентификатору последовательности, названию и тексту вопроса
выявил запись OEIS и исследование Де Влигера. Исторический приоритет
доказательств не установлен.
