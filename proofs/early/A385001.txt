Разбиения с отмеченными слагаемыми. Гипотеза Котешовца в A385001

Вацлав Котешовец 1 августа 2025 года предложил асимптотику для
суммы первых N элементов столбца k. Для любого фиксированного k ≥ 1
получается формула с оценкой остатка:

  Σ_{j=1}^N T(j,k) = π^(2k) N^(2k) / ((2k)! (2k+1)!)
                      + O_k(N^(2k−1) log(2N)).

Здесь T(j,k) считает разбиения j с k разными размерами частей:
среди всех копий части каждого размера выбирается одна отмеченная.
При кратности r имеется r вариантов отметки. Индекс относится к
различным размерам, а одинаковые экземпляры различаются для отметки.
https://oeis.org/A385001

1. Подсчёт при фиксированных размерах

Пусть m₁<…<m_k — фиксированные положительные размеры частей и
S = Σm_i. По обе стороны выделенного экземпляра размера m_i находятся
u_i и v_i экземпляров. Поэтому вклад этих размеров в сумму по j ≤ N
точно равен числу неотрицательных целочисленных точек области

     Σ m_i(u_i+v_i) ≤ N−S.

Заменив правую часть на X ≥ 0 и разрешив вещественные координаты,
получаем симплекс объёма V(X)=X^(2k)/((2k)! · Πm_i²). Это обычный
единичный симплекс после замены координат с множителями m_i.

Если S ≤ N, объединим полуоткрытые единичные кубы с левыми нижними
углами в подсчитанных точках. Объединение содержит весь симплекс
размера N−S, поскольку округление вниз сохраняет неравенство.
Оно содержится в симплексе размера N+S: увеличение каждой из двух
координат для m_i менее чем на 1 даёт в сумме прибавку менее 2S.
Объём объединения равен числу точек. Поэтому их число равно

     V(N) + O_k(S N^(2k−1)/Πm_i²).

Оценка следует из теоремы о среднем на [N−S,N+S] ⊆ [0,2N].
Если S>N, вклад равен нулю.

2. Суммирование

Сумма S/Πm_i² по S≤N оценивается сверху величиной
 k (Σ_{m≤N} 1/m)(Σ_{m≥1} 1/m²)^(k−1) = O_k(log(2N)).
Здесь можно отбросить ограничения порядка и различности, поскольку
все члены неотрицательны. Для S>N хотя бы одно m_i>N/k. Значит,
сумма 1/Πm_i² по пропущенным наборам равна O_k(1/N) по оценке
хвоста Σ_{m>N/k} 1/m². После умножения на N^(2k) эта ошибка
поглощается указанным остатком.

В главном члене остаётся коэффициент при t^(2k) в произведении

     Π_{m≥1}(1+t²/m²) = sinh(πt)/(πt).

Это произведение Эйлера для синуса при мнимом аргументе. Сравнивая
коэффициенты, получаем π^(2k)/(2k+1)!. Вместе с множителем
N^(2k)/(2k)! из объёма это доказывает формулу. В частности, при k=1
она даёт известный главный член π² N²/12 суммы функции делителей.

3. Связь с предшествующими работами

Столбцы — классические обобщённые суммы делителей Макмагона.
Их производящие функции представляют собой q-аналоги ζ(2,…,2).
Предельная теорема Бахмана–Кюна вместе с тауберовой теоремой
Харди–Литлвуда–Караматы для неотрицательных коэффициентов также
даёт главный член. Таким образом, отмеченная в OEIS гипотеза
следует из известных результатов. Приведённый здесь подсчёт
добавляет прямой вывод с явным порядком остатка. Приоритет для
этой оценки остатка не устанавливался.
https://arxiv.org/abs/1309.3920
https://arxiv.org/abs/2506.16131
