Доказательство общей проверки

Определим целые bₙ по первым N исходным членам и кандидатной линейной
рекурсии для всех n≥N. Положим uₙ=bₙbₙ₊₂−bₙ₊₁², vₙ=bₙ−uₙ. Докажем,
что uₙ≥0 и vₙ>0. Тогда bₙ=uₙ+vₙ>0, а 0≤uₙ<bₙ в точности означает
bₙ₊₂=⌈bₙ₊₁²/bₙ⌉. Единственность продолжения даёт aₙ=bₙ.

Пусть Vₙ=(bₙ,…,bₙ₊d₋₁). При n≥N−d имеем Vₙ₊₁=MVₙ, где M — матрица
линейной рекурсии. Первые две координаты Vₙ и Vₙ₊₁ образуют минор uₙ.
Поэтому uₙ и vₙ — линейные функции состояния
Yₙ=Vₙ ⊕ (Vₙ∧Vₙ₊₁) размерности D=d+d(d−1)/2. Его матрица перехода
есть M ⊕ ∧²M. Если берём каждый k-й член, матрица заменяется k-й степенью.

Для s=u или s=v проверяющий код выводит k, r и целые c₁,…,cᵣ. Для каждой
из k подпоследовательностей, начинающихся при n=80,…,79+k, он проверяет
равенство sₙ₊ᵣₖ=Σᵢcᵢsₙ₊₍ᵣ₋ᵢ₎ₖ на первых D последовательных шагах.
Его невязка тоже линейная функция состояния. По теореме Кэли–Гамильтона
D последовательных нулей в этой подпоследовательности влекут все остальные.
Поэтому найденная рекурсия верна на всём хвосте. Её первоначальное
угадывание не является предпосылкой доказательства.

Остаётся доказать положительность на хвосте. Используем напечатанные
рациональные границы 0<L≤H. Если последние r−1 отношений соседних членов
подпоследовательности лежат в [L,H], то следующее равно c₁ плюс сумма
cᵢ, делённых на произведения i−1 предыдущих отношений. Каждое слагаемое
лежит между cᵢ/Lⁱ⁻¹ и cᵢ/Hⁱ⁻¹, в порядке возрастания. Обе границы суммы
проверяются точно и лежат в [L,H]. Начальные отношения и положительность
первых членов в каждом классе также проверяются точно. При r=1 достаточно
проверить положительность первого члена и множителя. Индукция даёт
утверждение при n≥80. Для 0≤n<80 неравенства проверяются непосредственно.

Команда «python verify.py» воспроизводит все восемь сертификатов. Python
использует целые числа и Fraction. Файл certificates.txt содержит вывод.

Короткое доказательство для A048580

Пусть b₀=3, b₁=10, bₙ₊₂=4bₙ₊₁−2bₙ. Индукцией получаем bₙ₊₁>2bₙ>0.
Прямая подстановка даёт u₀=2 и uₙ₊₁=2uₙ. Поэтому uₙ=2ⁿ⁺¹<bₙ
для всех n≥0. Теперь применимо то же правило округления вверх.

Девятая последовательность, с округлением вниз

В A020750 заданы a₀=5, a₁=9 и aₙ₊₂=⌊aₙ₊₁²/aₙ⌋. В OEIS указан
вычислительный предел 40 000. Утверждаем, что для каждого n≥5

  aₙ=2aₙ₋₁−2aₙ₋₄+aₙ₋₅.

Пусть b — последовательность по правой части с начальными членами
5, 9, 16, 28, 49. Положим dₙ=bₙ₊₁²−bₙbₙ₊₂. Достаточно 0≤dₙ<bₙ.
Характеристический многочлен P(X)=(X−1)(X⁴−X³−X²−X+1).
После деления четвёртой степени на X² и замены t=X+X⁻¹ получаем
t²−t−3. Поэтому корни P различны и равны r,1,1/r,z,z̄, где r>1,
|z|=1, z+z̄=(1−√13)/2. Для каждого корня λ коэффициент в
bₙ=Σλ Cλ λⁿ равен Cλ=N(λ)/P′(λ), N=5X⁴−X³−2X²−4X+3.
Это следует из разложения Σ bₙ X⁻ⁿ⁻¹=N(X)/P(X) на простые дроби.

Раскрытие определителя даёт
dₙ=−Σ_{λ<μ} CλCμ(λ−μ)²(λμ)ⁿ, где суммирование идёт по всем
неупорядоченным парам различных корней. Положим A=Cᵣ. В dₙ/(A rⁿ)
пара (r,1) даёт постоянное (r−1)², поскольку C₁=−1. Две пары
(r,z),(r,z̄) вместе по модулю не превосходят 2|Cz|·|r−z|².
В остальных семи парах |λμ|≤1. Файл salem.py проверяет точной
рациональной интервальной арифметикой следующие оценки:

  1.72208380<r<1.72208381, 5<A<6, 0<C₁/ᵣ<1, |Cz|<0.031,
  0.50<(r−1)²<0.54, 2|Cz|·|r−z|²<0.39.

Здесь обозначение C₁/ᵣ в строке оценок означает C с индексом (1/r).
Для оценки |Cz|² вычисляются |N(z)|² и |P′(z)|² с помощью
zᵏ+z⁻ᵏ=t(zᵏ⁻¹+z¹⁻ᵏ)−(zᵏ⁻²+z²⁻ᵏ). Для n≥30 модуль суммы остальных
семи слагаемых ≤7·36·16/(5rⁿ)<0.01. Кроме того,
|bₙ/(Arⁿ)−1|≤4/(5rⁿ)<0.01. Следовательно,

  0.10<dₙ/(Arⁿ)<0.94<0.99<bₙ/(Arⁿ).

Для 0≤n<30 проверяем исходные целочисленные неравенства. Вместе это
доказывает утверждение для всех n. Команда «python salem.py» проверяет
точные границы, знаки на концах изолирующих интервалов и начальные члены.
