# Proof notes and certificates

The [results catalogue](../README.md#results) links each theorem to its proof and gives its Lean verification status.

From this directory, run `python find_witness.py` for Sun’s counterexample,
`python correct_mathar.py` for the corrected recurrence, and
`python verify.py` and `python salem.py` for the ceiling and floor Pisot sequences.
The rank-four matroid construction and its verification commands are in
[the family proof](rank-four-family.txt). These Python checks use the standard library.
