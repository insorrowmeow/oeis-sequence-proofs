# Два предположения Колина Баркера и бесконечное семейство рекурсий

В 2015 году Колин Баркер предположил линейные рекурсии для двух последовательностей со строгим округлением вниз. Для исходной пары $(2,16)$ коэффициенты равны $(8,0,-4)$, для $(2,32)$ — $(16,0,-8)$. Обе записи OEIS помечают формулы как гипотезы. [A022027](https://oeis.org/A022027) · [A022028](https://oeis.org/A022028)

**Теорема.** Пусть $x\ge2$ и $m$ — положительное целое, кратное $x$. Зададим $a_0=x$, $a_1=mx$. На каждом шаге берём наибольшее целое число, строго меньшее $a_{n+1}^2/a_n$. Тогда при $c=m/x$ для всех $n\ge0$ выполняется

$$a_{n+3}=m a_{n+2}-c a_n,\qquad
\sum_{n\ge0}a_n z^n=\frac{x-z^2}{1-mz+cz^3}.$$

Подстановка $(x,m)=(2,8),(2,16)$ даёт обе формулы Баркера. Для $(4,4)$ получаем также производящую функцию исходного правила из комментария Хаслера к A022030. В заголовке этой записи теперь стоит другое, чередующееся правило. [Комментарий к A022030](https://oeis.org/A022030)

### Доказательство

Построим целочисленную последовательность $b$ по линейной рекурсии из теоремы с начальными значениями $x,mx,m^2x-1$. Последнее число получается при первом строгом округлении. Достаточно доказать

$$0<D_n=b_{n+1}^2-b_n b_{n+2}\le b_n.$$

При $b_n>0$ это в точности условие $b_{n+2}<b_{n+1}^2/b_n\le b_{n+2}+1$. Следовательно, все шаги округления вынуждены.

Подстановка в линейную рекурсию даёт

$$D_0=x,\quad D_1=1,\quad D_2=m^2,\qquad D_{n+3}=mcD_{n+1}+c^2D_n.$$

Последнее равенство можно проверить раскрытием скобок: положим $u=b_n,v=b_{n+1},w=b_{n+2}$. Три следующих члена равны $mw-cu$, $m(mw-cu)-cv$, $m[m(mw-cu)-cv]-cw$. Подстановка этих выражений в обе части даёт одинаковый многочлен. Все $D_n$ строго положительны.

Сначала пусть $m\ge3$, и положим $R=5m/6$. Докажем, что $b_{n+1}\ge R b_n>0$ для всех $n$. Первые два отношения удовлетворяют оценке, поскольку $m^2x\ge6$. Если оценка верна для двух предыдущих шагов, то

$$b_{n+3}\ge(m-c/R^2)b_{n+2}\ge R b_{n+2}.$$

Второе неравенство равносильно $25m^2x\ge216$. Итак, $b_n\ge xR^n$. С другой стороны, $D_0,D_1,D_2\le x,xR,xR^2$ соответственно, а

$$\frac{mc}{R^2}+\frac{c^2}{R^3}
=\frac{36}{25x}+\frac{216}{125mx^2}\le\frac{108}{125}<1.$$

Рекурсия для $D_n$ теперь индукцией даёт $D_n\le xR^n\le b_n$.

Оставшийся случай $x=m=2$ имеет вид $b_n=F_{n+4}-1$, где $F_0=0,F_1=1$. Это следует из первых трёх членов и тождества $F_{k+3}=2F_{k+2}-F_k$. По тождеству Кассини при $k=n+4$ получаем $D_n=F_{k-2}+(-1)^k$. Отсюда $0<D_n\le F_k-1$ для $k\ge4$. Условие округления доказано во всех случаях. Умножение формального ряда на $1-mz+cz^3$ даёт заявленный числитель $x-z^2$. ∎
