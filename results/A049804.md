# Рекуррентная формула для суммы остатков

Пусть $b\ge2$ — целое основание, $n\ge1$, $k=\lfloor\log_b n\rfloor$. Обозначим через $s_b(n)$ сумму остатков от деления $n$ на $b,b^2,\ldots,b^k$. В 2019 году Петрос Хаджикостас предположил, что для каждой цифры $0\le r<b$ справедливо равенство

$$s_b(bn+r)=b\,s_b(n)+r(k+1).$$

В OEIS запись A049804 содержит как частный случай для $b=4$, так и общую формулировку. [Гипотеза Хаджикостаса](https://oeis.org/A049804)

**Доказательство.** Приписывание цифры $r$ справа к записи $n$ даёт число $bn+r$. Для каждого $j\ge0$ запишем $n=q b^j+t$, где $0\le t<b^j$. Тогда

$$bn+r=q b^{j+1}+(bt+r),\qquad 0\le bt+r<b^{j+1}.$$

Итак, остаток от деления нового числа на $b^{j+1}$ равен $b(n\bmod b^j)+r$. У нового числа на одну цифру больше, чем у $n$, поэтому остаётся сложить эти равенства для $j=0,\ldots,k$. Остаток $n\bmod b^0$ равен нулю, а добавка $r$ встречается $k+1$ раз. Получаем заявленную формулу.

Для базы 2 Роберт Израэль ранее записал ту же рекурсию в OEIS. Дирден, Ииамс и Мецгер в 2011 году рассматривали общую сумму и на странице 8 вывели близкую формулу через цифры. Из неё рекурсия также следует при сдвиге цифр на один разряд. Это даёт основание считать результат элементарным следствием прежней работы. [Запись для базы 2](https://oeis.org/A049802), [статья 2011 года](https://cs.uwaterloo.ca/journals/JIS/VOL14/Dearden/dearden3r.pdf)

В Lean 4.19.0 общая формула проверена теоремой RemainderSum.hadjicostas.
