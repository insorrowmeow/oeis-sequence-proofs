## Reproduction

Use Lean 4.19.0 and the pinned mathlib revision. Running **lake build** in this directory checks the listed Lean modules. The Python files accompanying the notes verify finite examples independently. They use standard Python, except for the optional polynomial scan [check_spectrum.py](spectra/check_spectrum.py), which uses python-flint. The finite computations supplement the all-index arguments.
