Задача A376452 повторяет формулировку о промежутках A376453 через дополнительную последовательность. Случай A050132 общей теоремы о перестановках имел опубликованный набросок доказательства уже в 2006 году. Для отдельной [гипотезы A050129](https://oeis.org/A050129) доказан список из семи возможных позиций вместо предполагаемых шести. Исключение дополнительной позиции 4n+4 остаётся открытым в этих материалах. Исторический приоритет результатов не установлен.

Для воспроизведения 30 свидетелей Фрёлиха в коротком доказательстве подставляются n=7·3ʰ−1 и модуль 3²ʰ. Слагаемые с j≥2h в разложении уже кратны этому модулю. Для оставшейся конечной суммы вычисляется точный 3-адический порядок после умножения на центральный биномиальный коэффициент. Доказательство для модуля 49 работает с любым числом семеричных разрядов, если в них есть хотя бы три цифры 3. Скрипт проверяет эти два достаточных условия. Для наименьшего свидетеля они независимо сверены с вычислением исходного триномиального коэффициента.

Дополнительная проверка [по первым 200 миллионам позиций](search_positions.ps1) последовательности A050128 не нашла случая T(n)=4n+4. Этот расчёт можно запустить в PowerShell. Он даёт конечное свидетельство для оставшегося случая A050129.

## Воспроизведение

Для формальных доказательств нужны Lean 4.19.0 и Mathlib с версией, зафиксированной в lake-manifest.json. В каталоге распакованного архива выполните команды ниже. В A308482 переход от коэффициента многочлена к вычислимой рекурсии доказан ядром Lean, а финальный численный остаток подтверждён через `native_decide`, с дополнительной зависимостью `Lean.ofReduceBool`. Минимальность второго примера подтверждает отдельный исчерпывающий Python-перебор. У основных теорем о промежутках и перестановках перечислены только стандартные `propext`, `Classical.choice`, `Quot.sound`.

```sh
lake exe cache get Mathlib.Data.Nat.Sqrt Mathlib.Tactic.Linarith Mathlib.Tactic.Ring Mathlib.Tactic.NormNum.Prime Mathlib.Data.Int.ModEq Mathlib.Algebra.Polynomial.Derivative
lake build
```

Остальные проверки используют стандартную библиотеку Python. Запускать их нужно без флага оптимизации. Полный перебор в последней строке медленнее остальных проверок. Для подтверждения одного числа 413343 достаточно быстрого сертификата.

```sh
python verify_gaps.py
python verify_double_half.py
python frohlich_certificate.py
python family_certificate.py
python verify_pisot.py
python visible.py
python frohlich.py 1000000
```
