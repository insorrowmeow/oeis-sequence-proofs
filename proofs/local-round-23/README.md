В рукописи второй задачи формализация отсчитывается от алгебраического уравнения производящей функции, выведенного в статье Волошина. [Список AutoGraphForge, запись 16](https://github.com/JanPastorek/AutoGraphForge/blob/main/results/audit_top.json#L258-L276) · [Формула (3.55) Волошина](https://arxiv.org/html/2611.11670v1#S3.SS7)

В каждом каталоге файл **check_lean.py** проверяет все локальные модули в Lean 4.19.0. Для проверки отдельной копии из среды mathlib v4.19.0 выполните **lake env python /путь/к/check_lean.py**. Независимые вычисления запускаются командами **python graph/verify_graph.py** и **python trees/verify_rows.py --through 28** из каталога этой подборки.
