# Две рекурсии для последовательностей Пизо

Для последовательности с начальными членами 4, 9 и правилом
`a[n+2] = ceil(a[n+1]^2/a[n])` верна рекурсия Чай Ва Ву

    a[n] = 3a[n−1] − 2a[n−2] + a[n−3] + a[n−4] − 2a[n−5] + a[n−6] − a[n−7]

при каждом n ≥ 7. В исходной записи указана проверка не менее чем на 760 000 членах. [OEIS A048582](https://oeis.org/A048582)

Для последовательности с начальными членами 4, 10 и правилом
`a[n+2] = floor(a[n+1]^2/a[n])` верна производящая функция, предложенная Ральфом Штефаном в 2004 году,

    Σ a[n] xⁿ = (4 − 2x − x² + x³ + 2x⁴ − 3x⁵) / ((1−x)(1−2x−x²−2x⁵)).

Суммирование начинается с n = 0. [OEIS A020748](https://oeis.org/A020748)

## Доказательство

В каждом случае берём последовательность b, заданную соответствующей кандидатной линейной рекурсией. Начальные члены приводятся в таблице. Запишем её рациональную производящую функцию в переменной z в виде Σ b[n]/zⁿ⁺¹ = N(z)/P(z). Коэффициенты в таблице перечислены от старшего к младшему. Число σ равно 1 для округления вверх и −1 для округления вниз.

| OEIS | σ | Начало b | P | N |
|---|---:|---|---|---|
| A048582 | 1 | 4, 9, 21, 49, 115, 270, 634 | 1, −3, 2, −1, −1, 2, −1, 1 | 4, −3, 2, 0, −3, 1, −2 |
| A020748 | −1 | 4, 10, 25, 62, 153, 377 | 1, −3, 1, 1, 0, −2, 2 | 4, −2, −1, 1, 2, −3 |

Положим Δ[n] = σ(b[n]b[n+2] − b[n+1]²). Достаточно доказать 0 ≤ Δ[n] < b[n] при всех n. Это даст b[n] > 0 и ровно то округление, которое определяет a.

Обозначим степень P через d. У многочлена d простых корней. Один из них вещественный r с 2 < r < 3, второй равен 1, а все остальные по модулю меньше 49/50. Расстояния между различными корнями превышают 1/4. Эти оценки следуют из рациональных сертификатов в конце доказательства. Разложение на простые дроби даёт b[n] = Σ Cλ λⁿ, где Cλ = N(λ)/P′(λ). Пусть A = Cᵣ. Сертификаты дают A > 1 и |Cλ| < B для B = 10⁹. Непосредственная подстановка даёт C₁ = 1/5 и −1/4 соответственно. В обоих случаях 1/5 < σ C₁(r−1)² < 4/5.

Раскрывая определитель попарно, получаем

    Δ[n] = σ Σ Cλ Cμ (λ−μ)² (λμ)ⁿ,

где сумма берётся по всем неупорядоченным парам различных корней. После деления на A rⁿ пара {r,1} даёт σ C₁(r−1)². Пары, содержащие r и внутренний корень, вместе имеют модуль не более (d−2)B·16·(49/50)ⁿ. Остальные пары имеют |λμ| ≤ 1, поэтому их суммарный вклад после деления по модулю меньше binom(d−1,2) B²·36 / 2ⁿ. При n ≥ 2000 сумма обеих оценок меньше 1/20. Аналогично |b[n]/(A rⁿ) − 1| < (d−1)B/2ⁿ < 1/20. Отсюда

    0 < 3/20 < Δ[n]/(A rⁿ) < 17/20 < 19/20 < b[n]/(A rⁿ).

Для 0 ≤ n < 2000 те же неравенства 0 ≤ Δ[n] < b[n] проверяются непосредственно над целыми числами. Тем самым a[n] = b[n] при каждом n.

## Как проверить оценки корней

В первой строке таблицы берём открытые круги радиуса 1/500 с центрами

    2.349, 1, −0.919, 0.316 ± 0.847i, −0.032 ± 0.752i.

Во второй строке центры имеют вид

    2.461, 1, 0.541 ± 0.759i, −0.772 ± 0.583i.

Все десятичные дроби здесь точные. Для каждого центра c и каждого k положим tₖ = P⁽ᵏ⁾(c)/k!, ε = 1/500. Программа проверяет

    max(|Re t₁|, |Im t₁|) ε > Σ (|Re tₖ|+|Im tₖ|) εᵏ   (k ≠ 1).

По теореме Руше P имеет внутри круга ровно один корень с учётом кратности. Круги попарно не пересекаются, и их число равно степени P. Круг с вещественным центром инвариантен относительно сопряжения, поэтому его единственный корень веществен. Оценки расстояний и модулей следуют из центров и радиуса. Поскольку P монический, |P′(λ)| — произведение d−1 попарных расстояний от λ. Отсюда |Cλ| ≤ 4ᵈ⁻¹ Σ |Nⱼ| 3ʲ < B. Для A > 1 программа ограничивает N(r) снизу и P′(r) сверху и снизу на вещественном отрезке своего круга.

Файл `verify_pisot.py` проверяет все указанные неравенства над рациональными числами и проверяет начальные члены над целыми. Для воспроизведения достаточно запустить `python verify_pisot.py`. Поиск по номерам OEIS и точным названиям последовательностей не выявил предыдущих доказательств именно этих двух формул. Общее направление представлено в [работе Эхада, Слоуна и Цайльбергера](https://arxiv.org/abs/1609.05570).
