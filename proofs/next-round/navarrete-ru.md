# Две перестановки Энрике Наваррете

Выписываем число 0. Затем каждый раз выбираем наименьшее ещё не использованное неотрицательное целое другой чётности, у которого есть общая десятичная цифра с предыдущим числом. Начало получается таким: 0, 101, 10, 1, 12, 11. Если начать с 1, первые числа будут 1, 10, 11, 12, 13. В 2018 году Энрике Наваррете предположил, что в каждом из двух списков встречается каждое неотрицательное целое. [A318698](https://oeis.org/A318698) · [A318699](https://oeis.org/A318699)

**Теорема.** При любом начальном неотрицательном целом этот алгоритм определён на каждом шаге и перечисляет все неотрицательные целые ровно по одному разу.

**Доказательство.** Назовём число универсальным, если в его обычной десятичной записи встречаются все десять цифр. Оно имеет общую цифру с любым числом, в том числе с нулём. Универсальных чисел каждой чётности бесконечно много. Например, к записи 1234567890 можно приписать справа сколько угодно нулей и затем цифру 0 или 1. На любом конечном шаге остаётся хотя бы одно неиспользованное универсальное число нужной чётности. Значит, процесс продолжается без конца. Повторы исключены правилом выбора.

Зафиксируем универсальное число $u$. Пока оно не использовано, на каждом шаге его чётности оно допустимо. Обойти его алгоритм может только выбором меньшего числа. Таких чисел лишь $u$, и каждое можно выбрать только раз. Шагов нужной чётности бесконечно много, поэтому $u$ обязательно встретится.

Теперь зафиксируем произвольное число $k$. В последовательности встретятся бесконечно многие универсальные числа противоположной чётности. Сразу после каждого из них $k$ допустимо, пока оно ещё не использовано. Снова обойти $k$ можно только выбором нового числа меньше $k$. После не более чем $k$ таких пропусков оно должно появиться. Это доказывает утверждение одновременно для обоих списков.

**Явная верхняя граница.** Положим $r=(k+1)\bmod 2$, $U_t=10^{11}t+12345678900+r$ и $H=U_k$. Числа $U_0,\ldots,U_k$ — различные универсальные числа противоположной $k$ чётности. Каждое из них появится не позднее индекса $2(H+1)$: среди шагов с 1 по $2(H+1)$ есть $H+1$ шагов его чётности, а меньших чисел не более $H$. После этих $k+1$ различных предшественников алгоритм на $k+1$ различных шагах мог выбрать $k$. Следовательно, индекс $k$ не превосходит $2(H+1)+1$, считая начальный член с нуля. Граница грубая и дана в письменной форме.

**Насколько далеко число может уйти от своего места?** Для любого фиксированного старта при $\alpha=\log_{10}9$ выполняется $a(n)=n+O((n+1)^\alpha)$. В частности, $a(n)/n\to1$.

Среди чисел до $X$ не более $O(X^\alpha)$ неуниверсальных. Действительно, для каждой из десяти пропущенных цифр есть не более $9^j$ допустимых записей длины $j$, а сумма по всем длинам до $\lfloor\log_{10}X\rfloor+1$ имеет указанный порядок. В каждом классе чётности среди чисел до $X$ имеется $X/2+O(X^\alpha)$ универсальных. Если $p_k$ — $k$-е из них в одном выбранном классе, то сначала получаем $p_k=O(k)$, а затем, подставляя $X=p_k$, получаем $p_k=2k+O(k^\alpha)$.

Перед шагом $n\ge1$ использовано не более $\lceil n/2\rceil$ чисел нужной чётности. Хотя бы одно из первых $\lceil n/2\rceil+1$ универсальных чисел этой чётности доступно. Это даёт $a(n)\le n+O((n+1)^\alpha)$. Теперь среди первых $N$ значений не более $O(N^\alpha)$ неуниверсальных, поскольку все значения различны и ограничены сверху величиной $O(N)$. На следующем за универсальным значением шаге алгоритм берёт наименьшее неиспользованное число нужной чётности. Среди первых $N$ шагов таких выборов для каждой чётности не меньше $N/2-O(N^\alpha)$. После $g$ выборов минимума в одном классе его первые $g$ чисел уже использованы. Поэтому $a(N)\ge N-O(N^\alpha)$, что завершает оценку. В [доказательстве для спирали](seq/digit-spiral.md) тот же подсчёт применяется к нескольким соседям.

В [формализации](Navarrete.lean) функция `walk` построена рекурсией с выбором минимального допустимого числа. Определение `HasDigit` исключает ведущие нули и учитывает единственную цифру числа 0. Теорема `permutation` доказывает биективность для любого старта. Её следствия `a318698` и `a318699` проверены Lean 4.19.0 с Mathlib без пропусков. Обе количественные оценки доказаны письменно. Отдельно опубликованный более ранний пример без чередования чётности — [A107353](https://oeis.org/A107353). Поиск по номерам двух записей не устанавливает приоритет.
