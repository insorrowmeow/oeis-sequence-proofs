## Проверка

В проекте закреплены Lean 4.19.0 и ревизия Mathlib. При установленном elan выполните в корне репозитория следующие команды.

```sh
lake exe cache get
lake build
```

Чтобы посмотреть, от каких аксиом зависит конкретная теорема, запустите её файл, например `lake env lean Sun.lean` или `lake env lean AntiRunWitness.lean`. Для численного примера Фрёлиха используется нативное вычисление с дополнительной аксиомой `Lean.ofReduceBool`. Минимальность и семейство из 30 примеров проверяются отдельными программами. [Поиск наименьшего решения](frohlich.py) · [Сертификат семейства](family_certificate.py)

В поиске решений, написании текстов и формализации использовался ИИ. В доказательствах указаны более ранние работы, в том числе по перестановке A050132, спектральной формуле для чисел с соседними цифрами, различающимися на единицу, и суммам делителей Макмагона. Где более раннее доказательство не указано, вопрос о приоритете остаётся открытым.
